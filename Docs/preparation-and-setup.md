# 準備と設定

チュートリアルに必要なリソースを準備し、IBM Bobの基本操作を理解します。

Lab 3・4 を実施するかどうかによって、手順が異なります。以下の基準を参考に選択してください。

## Lab 3・4 を実施するかどうかの基準

- **実施する場合**: GitHubを利用して、コードレビューやソース管理（コミットメッセージの作成、プルリクエストの作成）まで行うことができます。GitHubアカウントとGitが必要です。
- **実施しない場合**: GitHubを利用したコードレビューやソース管理はできませんが、FAQサイトの作成は行うことができます。
